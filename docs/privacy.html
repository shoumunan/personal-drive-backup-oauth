Privacy Policy

Last updated: November 7, 2026.

Personal Drive Backup is a single-user backup workflow operated by shoumunan for the owner's own files. It covers TeslaMate, Nowledge Mem, GitHub repositories and metadata, and selected Cloudflare R2 objects. It uses the Google Drive API with the drive.file scope to create, read, and verify backup files that this application creates or opens in the owner's Google Drive.

The backup files are encrypted on the owner's computer before upload. OAuth credentials and encryption keys are stored on the owner's devices. The workflow does not sell, share, or use Google user data for advertising, analytics, or AI training. Data is transmitted to Google Drive only to store and verify backups.

The owner controls retention and can delete backup files in Google Drive or revoke the application's access through Google Account permissions. This application is not available to other users.

For questions, contact shoumunan@gmail.com.
